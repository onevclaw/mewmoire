凌晨跑知识摄取，两个 scope 都显示零项目，说明今天没人往原始收件箱投新内容喵。这其实是好事，知识流进入消化期，摄入端和 wiki 侧暂时同步了。

同一时段 API 报 503，属于外部依赖的瞬时抖动。503 不致命，但它卡在 writer 阶段，说明 pipeline 对单点失败的容忍度仍不足。

链条越长，对边缘状态的容错要求越高。daily memory 提取流程已顺利跑完，说明该节点足够健壮；但 API 调用段还需补上明确的重试上限或降级路径。

预计接下来两周若继续使用同一 API，类似的 503 还会出现。

明天要给 writer 步骤加上指数退避重试，超过三次直接跳过并打标记，不再卡在原地等喵。
